# Barton Transcript Extraction Notes

Date: 2026-07-28

This file records the transcript-style notes that appear to be the best available source for Matthew and Evan's website direction.

## What appears to be the core message
Matthew's voice notes suggest a quote experience that is:
- friendly and game-like,
- simple enough for customers to complete quickly,
- structured around a few high-value decisions,
- and still grounded in real moving constraints such as distance, building access, items, and crew size.

## Key themes
- Start with a simple choice between contacting the company and building a move estimate.
- Use a set of regional area options rather than a long freeform route selector.
- Offer a fun, visual property type screen using apartment and house illustrations.
- Let customers select items in a shopping-cart style, not a long questionnaire.
- Add a box estimator and crew warning system to make the estimate more realistic.
- Support apartment-complex partner discounts and other promo codes.

## Why this matters for the website
These notes directly align with the current quote wizard in the repo, which already implements many of these ideas:
- location tiles,
- property-type selection,
- item categories,
- special items,
- boxes,
- crew recommendations,
- and coupon/promo support.

## Recommended next steps
- Keep the experience playful but don't overcomplicate it.
- Favor a small number of screens and intuitive choices.
- Make the estimate output feel trustworthy and useful, not just "game-like".
- Tie the quote flow to the broader growth strategy: reviews, referrals, and local video content.
