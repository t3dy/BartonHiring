# 20-point next-step summary for the Barton Moving project

1. Finish the quote wizard as the main conversion tool.
   - Technology: React + TypeScript + the existing quote flow.
   - What to learn: how state, screens, and form logic work in the current app.

2. Make the estimate experience feel simpler and more game-like.
   - Technology: UI components, screen transitions, and lightweight interaction design.
   - What to learn: how to reduce friction without losing trust.

3. Tighten the location selection flow.
   - Technology: form state, preset tiles, and custom-location handling.
   - What to learn: how to model common routes in a way that is easy for customers.

4. Improve the property-type screen.
   - Technology: visual UI and branching logic.
   - What to learn: how to ask the right questions for apartments versus houses.

5. Add or refine the box estimator.
   - Technology: simple rules-based logic and UI counters.
   - What to learn: how to turn rough inputs into a believable estimate.

6. Strengthen the crew recommendation logic.
   - Technology: conditional logic and pricing rules.
   - What to learn: how to explain why the recommended crew size matters.

7. Keep promo codes and partner discounts working smoothly.
   - Technology: pricing rules and form fields.
   - What to learn: how discounts change the estimate and how to present them clearly.

8. Connect the quote flow to the backend.
   - Technology: API endpoints and serverless functions.
   - What to learn: how frontend forms send data and how the backend stores it.

9. Learn the basics of Git and GitHub.
   - Technology: Git version control.
   - What to learn: commit, branch, pull, push, and basic collaboration.

10. Deploy and test through Vercel.
    - Technology: Vercel hosting and deployment.
    - What to learn: how to publish changes safely and review previews.

11. Learn the database basics in Supabase.
    - Technology: Supabase and SQL.
    - What to learn: how tables, rows, and simple queries work.

12. Add review-request automation.
    - Technology: backend workflows and email/SMS triggers.
    - What to learn: how to follow up after a job without making it feel spammy.

13. Build a referral flow for past customers.
    - Technology: promo logic and simple user flow.
    - What to learn: how to turn a good experience into repeat business.

14. Create a lightweight content system for local SEO.
    - Technology: static pages, routing, and basic SEO markup.
    - What to learn: how neighborhood pages and service pages attract local search traffic.

15. Set up a simple lead-tracking dashboard.
    - Technology: analytics, event tracking, and basic reporting.
    - What to learn: which channels produce actual quotes and calls.

16. Learn the basics of video repurposing.
    - Technology: YouTube, Shorts, Reels, and scheduling tools.
    - What to learn: how one video can become many pieces of marketing content.

17. Improve accessibility and clarity.
    - Technology: semantic HTML, keyboard support, good labels, and readable copy.
    - What to learn: how to make the site usable for everyone.

18. Learn the basics of performance and image optimization.
    - Technology: image formats, compression, and bundle size.
    - What to learn: how to make pages load fast on mobile.

19. Learn the basics of security and environment configuration.
    - Technology: environment variables, secrets, and safe deployment settings.
    - What to learn: how to keep passwords and keys out of the app code.

20. Prioritize the work by business impact.
    - Technology: product thinking and simple project planning.
    - What to learn: how to focus on the steps that most improve quote volume, trust, and conversion.
